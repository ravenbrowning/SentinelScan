# SentinelScan 🛡️

## Cybersecurity Assessment Platform

SentinelScan is a cybersecurity assessment platform designed to help users identify security weaknesses through automated checks, risk scoring, and security reports.

---

# Features

## Current

- Project foundation
- API health monitoring
- Docker development environment


## Planned

- User authentication
- Security dashboard
- Password analysis
- File integrity monitoring
- Domain security checks
- Security reports
- Vulnerability tracking
